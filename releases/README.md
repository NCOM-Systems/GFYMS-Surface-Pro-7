# GFYMS releases

Every public release is intended to have three primary forms:

1. **GFYMS Arch Surface Patcher** — update an existing Arch/Arch-based Surface Pro 7 installation.
2. **GFYMS Surface Pro 7 ISO** — clean Arch + KDE Plasma installation image.
3. **GFYMS USB Tool** — verify, write and validate the release ISO to removable media.

Additional release evidence:

- SHA-256 checksum
- detached signature
- package repository snapshot
- hardware qualification report
- known issues
- changelog

The release channel should distinguish `stable`, `testing`, and experimental/nightly builds.
