# GFYMS project assets

This directory contains the current raster branding and Surface device hero assets used during development:

- `NCOM Systems Full Hero Logo Black.PNG` — light-background NCOM Systems mark.
- `NCOM Systems Full Hero Logo White.PNG` — dark-background NCOM Systems mark.
- `NCOM Systems OijaBoard Black Logo.png` and `NCOM Systems OijaBoard White Logo.png` — current OuijaBoard development marks. The historical `OijaBoard` spelling is retained in the filenames for compatibility; new files and code should use `OuijaBoard`.
- `MS Surface *.png` — provisional Surface device hero artwork.

The current files are raster development assets, not yet the final canonical GFYMS brand package. Before a stable release, add an approved `gfyms-logo.svg` source and matching transparent PNG exports, then record dimensions, background assumptions and intended use in an asset manifest.

README, GitHub social preview, ISO branding and KDE integration should use the same approved canonical asset. Do not regenerate, replace or alter the user's personal mark without explicit approval.
