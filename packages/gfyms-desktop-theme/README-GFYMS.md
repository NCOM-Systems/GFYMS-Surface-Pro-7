# GFYMS desktop theme

This package supplies the GFYMS dark KDE color scheme and a small branded icon theme.

The icon theme provides the GFYMS Center mark and inherits Breeze for icons GFYMS does not own. It does not replace third-party application artwork. The color palette is dark, high-contrast and restrained so controls remain legible on small Surface screens.

This is a GFYMS visual system, not a claim that KDE or every third-party application is forcibly restyled. Users can change the KDE theme in System Settings.
