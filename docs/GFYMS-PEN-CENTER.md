# GFYMS Surface Pen Center

Microsoft documents Surface Pen pressure adjustment through the Surface app, battery/status information, and configurable pen behavior.

GFYMS Center mirrors those user-facing categories with a native Qt interface.

Current controls:
- pressure response
- writing hand
- top-button action
- side-button action
- pen status guidance

The next hardware backend stage connects those preferences to the Surface IPTS/HID/uinput path. The Microsoft Surface application itself is not bundled or executed on Linux.
